# 🏴‍☠️ Qaroqchi Zeboxon — Retro 2D Sarguzasht O'yini 🏝️

Retro pikselli 2D qaroqchilik sarguzasht o'yini. O'yinchi xavfli orollarda xazinalar va oltin kalitlarni qidiradi, dushmanlar va tuzoqlardan himoyalanadi, ilm-fan savollariga javob berib qobiliyatlarini kuchaytiradi!

---

## 🎮 Asosiy Imkoniyatlar va Xususiyatlar

- **🏝️ 10 Ta Qiyinlashib Boruvchi Orol**: Har bir bosqich o'ziga xos labirint, dushmanlar, xazinalar va bosslar bilan boyitilgan.
- **⚔️ Qilich Bilan Jang**: Qisqichbaqalar, skeletlar, arvohlar va qaroqchilarga qarshi qilich silkiting.
- **📚 Bilimdonlik va Qochish Tizimi (Quiz Escape)**:
  - Matematika 🔢
  - Ingliz tili 🇬🇧
  - Geografiya 🌍
  - Aralash fanlar 🎲
  - To'g'ri javob berganda dushmanlar karaxt bo'ladi, tutun buluti portlaydi va qo'shimcha **+15 soniya vaqt bonusi** beriladi!
- **⏱️ Bosqich Taymeri (Level Countdown Timer)**: Har bir bosqich uchun maxsus vaqt me'yori, ogohlantiruvchi ovoz va visual effektlar.
- **🧭 Ishora Tizimi (Kompas)**: Kalit va xazina sandig'igacha bo'lgan masofa va yo'nalishni ko'rsatuvchi interaktiv indikator.
- **📱 To'liq Mobil va Sensorli Moslashuvchanlik**:
  - D-Pad va qilich / qochish tugmalari.
  - Har qanday telefon ekraniga (vertikal va gorizontal) mos keluvchi responsive dizayn.
  - Ortiqcha elementlarni ixcham **Burger Menyu (☰)** ichiga yashirish.
- **🎵 Retro Audio Effektlar**: Web Audio API orqali sintezlangan retro musiqa va tovushlar (zarba, tanga, kalit, taymer chertilishi, g'alaba).

---

## 🚀 O'yinni Ishga Tushirish

Loyihani kompyuterda ishga tushirish uchun Node.js kerak bo'ladi:

```bash
# Serverni ishga tushirish
node server.js
```

Brauzerda quyidagi manzilni oching:
```
http://localhost:3000
```

Yoki to'g'ridan-to'g'ri `index.html` faylini istalgan brauzerda ochib o'ynash mumkin.

## 🕹️ Boshqaruv

- **WASD / Strelkalar**: Harakatlanish
- **SPACE / Sichqoncha / Z / J**: Qilich zarbasi
- **Q**: Tezkor savol-javob orqali qochish
- **P**: Pauza
- **M**: Ovozni yoqish / o'chirish
- **F**: To'liq ekran (Fullscreen)
- **Mobil**: Ekrandagi sensorli D-Pad, ⚔️ Qilich va ⚡ Qochish tugmalari
